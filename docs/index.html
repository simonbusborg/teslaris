Features

Small app, sharp focus.

Live, but frugal

Refreshes every 15 minutes — every minute while charging, when the numbers actually move. Nothing polls your car to death.

Never wakes the car

A sleeping Tesla stays asleep — wakes cost API credit and battery. You see the last known data, marked as such.

Charging notifications

Charging started, charging complete, charger lost power. Each one can be turned off.

Keychain, not plaintext

Credentials and session tokens live in the macOS Keychain. Nothing is written to disk in the clear.

Read-only by design

Teslaris requests one scope: vehicle_device_data. It cannot unlock, wake, or drive your car.

Native and tiny

Pure AppKit. One small binary. No Electron, no SwiftUI, no background services, MIT licensed.

Costs

Free — by architecture, not by promise.

Tesla bills Fleet API usage per request, and grants every developer account $10 of free credit each month. Teslaris has no server and ships no shared API key: you register your own (free) Tesla developer application once, and the app's modest polling — roughly $5–8/month of usage — stays comfortably inside your own free credit. There is nothing to subscribe to, and no third party ever sees your data.

Setup

One-time setup, ~20 minutes.You'll never touch it again.

1

Generate a key pair

Tesla requires registering a public key, even for read-only apps. In Terminal:

openssl ecparam -name prime256v1 -genkey -noout -out private-key.pem
openssl ec -in private-key.pem -pubout -out com.tesla.3p.public-key.pem

Keep private-key.pem somewhere safe. Teslaris never needs it — it only matters if you later want vehicle commands.

2

Host the public key

Tesla verifies your app by fetching the public key from a domain you control, at exactly this path:

https://YOUR-DOMAIN/.well-known/appspecific/com.tesla.3p.public-key.pem
Easiest way: a GitHub Pages site. Create a repository named username.github.io, commit the key file under .well-known/appspecific/, and it's live at https://username.github.io/… a minute later.
3

Create your Tesla developer app

Sign in at developer.tesla.com with your Tesla account → Create new application. It's free.

Use your domain from step 2 as the Allowed Origin, add http://localhost:8973/callback as an Allowed Redirect URI, and request the vehicle_device_data scope. Note the Client ID and Client Secret.

4

Let Teslaris do the rest

Open Teslaris → Settings… → paste your Client ID, Client Secret and key domain, pick your region, then click Register App with Tesla — the app performs the one-time partner registration for you (this used to be a curl incantation).

Then Save & Sign in with Tesla… — your browser opens Tesla's own login page, and you're done.

FAQ

Questions, answered plainly.

Is my data safe?

Teslaris talks only to Tesla: the official Fleet API for your car's data, and Tesla's public image renderer for the car picture. There is no Teslaris server, no analytics, no third party. Credentials and tokens are stored in the macOS Keychain.

Will it wake my car or drain the battery?

No. Teslaris never wakes a sleeping vehicle — it shows the last known data, marked as such, until the car wakes on its own. Wakes cost API credit and vampire-drain the battery, so not waking is a feature, not a limitation.

Can it unlock or control the car?

No. The only scope Teslaris ever requests is vehicle_device_data — read-only. Even if you wanted it to open the trunk, it can't.

Why do I need my own Tesla developer app?

Tesla bills API usage per developer account, with $10/month free. If Teslaris shipped one shared key, all users would drain a single account and the app would have to charge a subscription. With your own free key, your usage stays inside your own free credit — forever free, structurally.

Which cars are supported?

Model S, 3, X and Y, in North America / Asia-Pacific and Europe / Middle East / Africa. Cybertruck works too, minus the car picture. China isn't supported yet (Tesla uses a separate auth system there).

Is this a Tesla product?

No. Teslaris is an independent, MIT-licensed open source project and is not affiliated with, endorsed by, or sponsored by Tesla, Inc. "Tesla" and the model names are Tesla's trademarks, used only to describe compatibility.
